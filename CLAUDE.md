# Regra Mais Importante

Sempre desenvolver pensando que o LavTech é um software proprietário da empresa.

O foco deve ser:

* Código limpo
* Facilidade de manutenção
* Escalabilidade
* Excelente experiência do usuário
* Consistência arquitetural

Se existir mais de uma solução possível, priorizar a mais simples, legível e sustentável a longo prazo.
